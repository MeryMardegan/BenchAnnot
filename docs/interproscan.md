# InterProScan

## Overview
InterProScan annotates protein sequences against multiple domain and family databases (Pfam, PANTHER, CDD, SMART, TIGRFAM, and others). It adds functional predictions, GO terms, and pathway annotations.

In this pipeline, the module consumes proteins generated by GFFREAD and produces standardized TSV and GFF3 outputs.

## Requirements
- Container: `interpro/interproscan:5.75-106.0`
- InterProScan data directory downloaded locally.

## Database Location
Download and unpack the InterProScan data files, then set the directory in `nextflow.config`:

`params.ips_data_dir = "${projectDir}/data/eukaryotes/db/interproscan/interproscan-5.75-106.0/data"`

The pipeline binds this directory into the container as:
`/opt/interproscan/data`

## Input
- `${sample_id}.faa` (protein FASTA from GFFREAD)

## Output
- `${sample_id}.interpro.tsv` (domain and functional hits)
- `${sample_id}.interpro.gff3` (GFF3 annotations)

All outputs are stored in:
`results/eukaryotes/interproscan/`

## Parameters
- `--ips_formats` (default: `tsv,gff3`) controls output formats.

## Example Run
```bash
nextflow run main.nf -entry eukaryotes_annot
```

## Notes
- CPU/memory/time limits are defined globally in `nextflow.config`.
- Ensure the InterProScan data directory is readable by the container runtime.
